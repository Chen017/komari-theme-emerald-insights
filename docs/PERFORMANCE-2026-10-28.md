# 2026-10-28 性能优化与验证

保持 Vue、Pinia、现有组件库和插件 API；没有新增运行时依赖，也没有修改 IPQuality 检测核心。改动以加载等待、重复计算及重复读写为主。

## 修改范围

- 主题启动：健康检查后并行读取公开设置、登录状态与节点数据；全部就绪后仍按用户配置启动通信与轮询。
- 节点更新：每批建立 UUID 索引，替代为每个状态重复查找整个节点列表。
- Ping：实时 CPU、流量等字段更新时，UUID、查询范围和启用状态不变就复用统计结果；节点、范围及启用状态变化仍会正常更新。
- IPQA 快照：近期变动请求与快照读取解耦，慢查询不会阻挡当前快照。历史请求仍有加载状态、错误提示和重试。
- IPQA 存档：页面内最多缓存 64 个有效快照、有效期 30 秒；合并相同的进行中请求。失败、空报告和日期不匹配的结果不缓存；刷新、切换节点及离开页面清理缓存。不写入浏览器持久存储。
- 历史时间轴：只读快照使用浅响应式；密集完成的请求每 32 ms 最多发布一次中间进度，完成时仍发布全部日期。七类时间轴、变化感知采样、完整展开、日期范围、两日对比、协议隔离和失败重试保留。
- 资源概览：刷新完成后立即结束加载，去掉固定等待 600 ms。
- IPQA 终端：IPv6 近邻配对先排除 300 秒窗口之外的日期；继续支持跨午夜、三种时间戳格式、精确命中与相同距离的既有优先顺序。存档列表用 Bash 内建路径操作，并在当前菜单会话内复用元数据及配对；重新打开菜单重新读取。
- 在线率插件：日志的残缺尾行恢复检查改为首次追加或追加失败后进行；每次成功追加都带换行。统计先按节点和观测缺口分类，避免每个节点及时间片扫描所有事件。断线宽限、多连接、缺口恢复、保留期压缩及未知时间规则保留。
- IPQA 插件：批量重建每日报告时只在全部新日报写入后发布一次 latest，保留日期验证、旧日期清理和单日报保存接口。

## 验证和交付

- 主题：64 项回归、Vue / TypeScript 检查、本次修改文件 ESLint、生产 Beta 构建。
- IPQA 脚本：70 项完整离线回归，覆盖 DB-IP、Lite、awk 兼容、路径保护、双栈及存档专项；修改的脚本通过 ShellCheck 和 Bash 语法检查。
- IPQA 插件：102 项回归与 TypeScript 检查。
- 在线率插件：33 项回归与 TypeScript 检查。
- Chromium：标签切换、七类时间轴、日期分页、前后日期交换、未变化项目、IPv4 / IPv6、390px 明暗模式；额外检查失败重试和切换节点时的过期响应。
- 主题全仓 lint 仍有旧文件及旧文档中的既有问题，本次修改文件通过；既有 ECharts 大分块提示仍保留。

主题使用 `bun run build:beta`。两个插件使用 `npm run build:beta`，仅在安装包内标记 `-beta.performance.g<sha>`，正式版本字段不变；普通构建仍输出原有文件名。IPQA 脚本以包含本地 `install.sh` 和 `ipqa.sh` 的 ZIP 交付，在 Linux 解压后运行 `bash install.sh` 使用同目录脚本。所有包放入桌面交付目录，并附 SHA-256；代码推送性能分支，不创建 tag 或 GitHub Release。

## 第二轮：资源概览首次导航与存档整页显示

资源概览的流量卡片改用现有 Vue 异步组件方式加载，页面标题、在线率、IPQA 与成本卡片不再等待 ECharts 下载。图表加载期间显示占位卡，图表和筛选、统一刷新功能照常加载。ECharts 仍为原有引擎，没有减少功能或更换框架。

共享路由加载函数供导航和预加载使用。启动完成、资源概览启用且浏览器空闲时，提前获取轻量页面模块；鼠标经过、键盘聚焦或触摸按钮时也可触发。预加载不加载图表，不启动概览数据请求；组件卸载或功能禁用时取消待执行的空闲任务。资源概览自身模块约 98 → 46 kB（未压缩），约 687 kB 的 ECharts 从整页首次显示的等待路径移出，总体功能代码保持存在。

生产构建 Chromium 测试人为给页面模块增加 180 ms 延迟、图表引擎增加 900 ms 延迟：修改前首次页面可见约 1.39 秒；修改后直接点击约 0.15–0.26 秒，空闲预加载完成后约 79 ms，且页面出现时图表引擎仍在加载。断言空闲预加载阶段没有图表、流量、在线率或 IPQA 数据请求；随后图表 canvas、30 天范围切换、统一刷新、再次进入与 390px 布局均通过，无页面运行错误。这是固定延迟模拟，真实耗时取决于网络和设备。

脚本端改为按页批量读取元数据、懒建日期索引并一次输出完整列表，减少逐行等待。详见 IP-Quality-Archive 的同名性能说明。本次只更新主题和 IPQA 脚本包，两个插件沿用上一轮通过验证的版本。主题继续推送性能分支；脚本同时同步 main，避免自带自动更新覆盖优化。没有 GitHub Release。
